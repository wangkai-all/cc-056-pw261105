# 用量分档计费演示

合同按用量分档收费的计费系统：晚到用量或冲正也能补出正确账单。
页面维护客户、服务项目、带发生日期和唯一编号的用量、计费规则，并可查看每月收费明细及每笔更正。

技术栈：**FastAPI + SQLite + Python（Decimal 计费引擎）+ React（Vite）**

## 计费办法约定（本项目口径）

1. 同一服务项目**按月累计**；规则整月不变时，全月用量走一次完整阶梯，**每档只收落入该档的量**（累进式）。
2. 应收 = 固定费 + 用量费；**低于最低消费补足到最低消费**，已达到则不补。
3. 规则只在**自然日零点生效**；月中变更时按生效区间**拆段**，每段用量**分别走完整阶梯阈值**，
   固定费与最低消费按 **段有效天数 / 当月天数** 折算。页面明确展示分段，不与整月累计混算。
4. 全部用 **Decimal** 计算，月合计最后**四舍五入保留到分**（中间折算值保留完整精度）。
5. **封存账单不覆盖**：每次收到晚到或冲正用量，先完整重算当月应付，
   再减去原账单和之前已封存更正单的合计，**只开剩余差额**（更正单，可为负）。
6. **冲正引用原用量**，累计冲正不能超出原量；冲正归到原单发生月参与重算。
7. 用量带**唯一编号**，重复导入不再计费；每项金额都能追到具体规则与用量（账单内含快照明细）。

## 目录结构

```
backend/
  app/
    billing.py   # 计费引擎：纯函数 + Decimal，不依赖数据库
    service.py   # 服务层：数据库读写 + 调引擎（API 与演示数据共用）
    db.py        # SQLite 连接与表结构（金额/数量以 TEXT 存 Decimal）
    main.py      # FastAPI 路由 + 托管前端构建产物
    seed.py      # 演示场景：全部通过真实引擎跑出
  tests/         # pytest：引擎单测 + API 集成测试
frontend/
  src/           # React 单页应用（演示场景/账单/用量/计费规则/客户与项目）
```

## 快速开始

```bash
# 1. 后端依赖（建议虚拟环境）
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt

# 2. 构建前端（已构建可跳过，产物在 frontend/dist）
cd frontend && npm install && npm run build && cd ..

# 3. 启动（单服务：API + 前端页面）
cd backend && ../.venv/bin/uvicorn app.main:app --port 8000
```

打开 http://localhost:8000 ，在「演示场景」页点 **重置并载入演示数据**。

开发模式（前端热更新）：`cd frontend && npm run dev`（Vite 代理 /api 到 8000 端口）。

## 演示场景

| 场景 | 数据 | 结果 |
| --- | --- | --- |
| 跨档 | 甲公司 API调用 2026-03，6200 次 | 1000×0.10 + 4000×0.08 + 1200×0.05 + 固定50 = **530.00** |
| 二月 | 乙公司云存储 2026-02（28 天），02-15 换规则 | 两段各 14/28 折算：54.00 + 60.50 = **114.50** |
| 月中升级 | 甲公司 2026-05，05-16 零点新规则 | 15/31 段 284.19… + 16/31 段 396.29… = **680.48** |
| 连续两次更正 | 甲公司 2026-04 | 原单 **174.00** → 晚到 400 次补 **+32.00** → 冲正 500 次退 **−40.00**（应付合计 166.00） |

种子脚本同时演示：重复导入同一唯一编号被忽略且重算无差额；对 800 次原单冲正 900 次被拦截。


四舍五入到分、冲正净额、无规则报错、连续更正差额、重复导入幂等、冲正超量拦截、规则校验。

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/api/customers` | 客户 |
| GET/POST | `/api/service-items` | 服务项目 |
| GET/POST/DELETE | `/api/rules[/{id}]` | 计费规则（同客户+项目+生效日覆盖更新） |
| GET/POST | `/api/usage` | 用量/冲正（唯一编号幂等） |
| POST | `/api/usage/import` | 批量导入（重复跳过、逐条报错） |
| GET | `/api/bills/preview` | 只重算不落库 |
| POST | `/api/bills/generate` | 出账：重算 − 已封存合计 = 差额单 |
| GET | `/api/bills[/{id}]` | 账单列表 / 含快照的明细 |
| POST | `/api/demo/reset` | 重置并载入演示数据 |
